# Соответствие требованиям РФ — практический чек‑лист (CLUB-OPS)

> ⚠️ **Это не юридическое заключение.** Документ — практический технический
> чек‑лист для подготовки к работе с персональными данными (ПДн) на российской
> инфраструктуре. Он **не подтверждает** автоматическое соответствие
> законодательству. **Финальную проверку и оформление документов должен
> выполнить юрист** (специалист по 152‑ФЗ «О персональных данных» и смежным
> требованиям). Не запускайте обработку реальных ПДн в проде до юридической
> проверки.

CLUB-OPS обрабатывает данные, которые могут относиться к персональным:
сотрудники (зарплата, авансы, премии), клиенты (возвраты, ФИО, телефон),
реквизиты, загруженные документы (чеки, счета, заявления).

---

## 1. Размещение данных в РФ
- [ ] Сервер приложения размещён в РФ.
- [ ] PostgreSQL размещён в РФ.
- [ ] Объектное хранилище (S3) размещено в РФ.
- [ ] Резервные копии хранятся в РФ.
- [ ] Первичная запись и хранение ПДн граждан РФ — на территории РФ
      (требование о локализации). Конкретику подтверждает юрист.

## 2. AI / внешние сервисы
- [ ] В продакшене `AI_PROVIDER` = `mock` или `ru_ai`. OpenAI — **только dev/test**.
- [ ] **Не отправлять** зарплатные ведомости, ФИО, телефоны, реквизиты и иные ПДн
      в зарубежные AI/OCR‑сервисы без законного основания и согласия.
- [ ] При включённом OpenAI приложение логирует предупреждение
      («OpenAI is enabled…») — это сигнал, а не разрешение. Юрист подтверждает основание.
- [ ] Любая передача данных третьим лицам (включая AI‑провайдеров) отражена в
      политике и согласии.

## 3. Юридические документы (готовит/проверяет юрист)
- [ ] Политика обработки персональных данных (публичная).
- [ ] Согласие на обработку персональных данных (сотрудники и клиенты).
- [ ] Договор оказания услуг / SaaS‑соглашение (условия использования).
- [ ] Уведомление в Роскомнадзор об обработке ПДн (если требуется) — по решению юриста.
- [ ] Поручение на обработку с подрядчиками (облако, хостинг), где применимо.

## 4. Политика хранения данных (retention)
- [ ] Определены сроки хранения по типам данных (документы, логи, ПДн сотрудников/клиентов).
- [ ] Определён порядок удаления/архивирования по истечении срока.
- [ ] Архивирование клубов/сущностей не нарушает требований к хранению финансовых данных.

## 5. Роли и доступ
- [ ] Доступ — по принципу минимальных привилегий (owner / regional_director /
      manager / accountant), данные изолированы по компаниям/клубам.
- [ ] Доступ к ПДн только у ролей, которым это необходимо.
- [ ] Регулярный пересмотр прав доступа.

## 6. Аудит и журналирование
- [ ] Действия с документами и сменой статусов фиксируются в журнале аудита
      (таблица `AuditLog`).
- [ ] Журналы защищены от несанкционированного изменения и хранятся в РФ.
- [ ] Логи приложения не содержат секретов (ключей, паролей) и тел документов.

## 7. Резервное копирование
- [ ] Регулярные бэкапы БД и объектного хранилища (см. `RU_DEPLOYMENT.md`).
- [ ] Копии шифруются и хранятся в РФ.
- [ ] Периодически проверяется восстановление из копий.
- [ ] Срок хранения копий согласован с политикой retention.

## 8. Безопасность
- [ ] HTTPS/TLS на внешнем периметре (nginx или балансировщик провайдера).
- [ ] `SESSION_SECRET` — длинный случайный, хранится как секрет.
- [ ] Секреты (БД, S3, ключи) — в секрет‑менеджере, не в репозитории.
- [ ] S3‑бакет приватный; файлы отдаются только через приложение с проверкой прав.
- [ ] Обновление зависимостей и базовых образов.

## 9. Процедура реагирования на инциденты
- [ ] Назначены ответственные и контакты.
- [ ] Описаны шаги: обнаружение → локализация → устранение → уведомление →
      разбор причин.
- [ ] Определены сроки и порядок уведомления субъектов ПДн и регулятора
      (Роскомнадзор) — согласуются с юристом.
- [ ] Ведётся реестр инцидентов.

---

## Итог
Технические предпосылки для работы в РФ‑правовом поле этот проект поддерживает
(размещение данных в РФ, приватное хранилище, отключаемый внешний AI, аудит,
ролевой доступ). Однако **соответствие закону определяется не кодом, а
организационно‑правовыми мерами и документами**, которые должен подготовить и
утвердить юрист. Используйте этот чек‑лист как отправную точку для такой проверки.
