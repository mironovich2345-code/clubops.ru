# Управляющий — краткая инструкция

**Вход:** ваш email + пароль → код из письма (2 шага). Вы видите **только свой клуб**.

## Ежедневно
- **Расход наличными:** «Новый расход» → выберите статью, сумму, дату (текущий месяц), комментарий → **прикрепите 1–3 документа** → «Отправить». Статус появится в списке.
- **Счёт:** загрузите счёт (ИИ распознает поля) → проверьте → отправьте на проверку регионалу.
- **Возврат клиенту:** «Новый возврат» → тип (абонемент/ПТ) → загрузите документы + реквизиты → отправьте регионалу.
- **Наличные:** зафиксируйте инкассацию/изъятие; **подтвердите передачу денег регионалу** (пока не подтвердите — деньги не считаются переданными).
- **Контрольный остаток:** внесите фактические наличные на дату.

## Критичные ошибки (не делайте)
- Не отправляйте расход **без документа** — кнопка объяснит, чего не хватает.
- Не считайте счёт оплаченным, пока бухгалтер не провёл оплату.
- Возврат «на доработке»: если не получается заново приложить документ — обратитесь в поддержку (известное ограничение UX-001).

## Что нельзя
Вы не видите прибыль, аналитику сети, действия других клубов — это нормально.

## Конец дня
Все расходы/счета отправлены; наличные посчитаны; передача регионалу подтверждена.
**Куда обращаться:** поддержка (скопируйте ссылку из адресной строки нужной записи).
