# Бухгалтер — краткая инструкция

**Вход:** 2 шага. Вы попадаете на **Рабочий стол** (очереди задач), не на дашборд.

## Ежедневно
- **Оплата счёта:** откройте счёт → проверьте данные (ИИ + предупреждения) → «Оплачено полностью/частично» → способ (наличные/безнал) → дата. Виден **остаток** и причина, если оплату продолжить нельзя.
- **Частичная оплата:** укажите сумму; остаток пересчитается; можно платить несколько раз.
- **Уже оплаченный счёт:** «Исторический счёт» → дата счёта, дата оплаты, сумма.
- **Возвраты:** проведите оплату (выберите юрлицо, дату).
- Проверьте продажи, ближайшие оплаты, наличные расходы, обязательства.

## Критичные ошибки
- Не платите по счёту с красной плашкой «проверьте данные» — сначала проверьте и сохраните.
- Двойной клик по «Оплатить» — избегайте (защита есть у счетов; у зарплаты — известное ограничение REM-01).

## Что нельзя
Сторно платежа — только у **главного бухгалтера**. Закрытие месяца — тоже.

## Конец дня
Очереди «к оплате» разобраны; частичные оплаты корректны.
