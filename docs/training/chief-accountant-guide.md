# Главный бухгалтер — краткая инструкция

Всё, что делает бухгалтер, **плюс**:

## Сторно (только вы)
- **Сторно платежа по счёту:** в истории оплат счёта → «Сторнировать» → **укажите причину**. Платёж помечается reversed (не удаляется), статус счёта восстанавливается, остаток пересчитывается. История покажет: кто, когда, причина, что стало.
- **Сторно зарплатной выплаты:** через отмену выплаты в карточке расчёта.
- **Сторно обязательства «Зарплата к выплате»:** пока **нет кнопки** (известное ограничение UX-003) — обратитесь в поддержку.

## Закрытие месяца
- Закрыть месяц можно только после проведения выплат и без открытых заявок на изменение.
- Переоткрытие месяца утверждает **собственник**.

## Критичные ошибки
- Сторно без причины — система не даст.
- Проверьте, что «Выплачен» соответствует остатку (известное ограничение UX-004) — сверяйте по сотрудникам.
