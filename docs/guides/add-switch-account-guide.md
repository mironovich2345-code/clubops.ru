# Несколько аккаунтов на одном устройстве

CLUB-OPS позволяет держать несколько независимых аккаунтов на одном телефоне/компьютере и быстро
переключаться между ними без повторного ввода пароля (пока сессия активна).

Это **не** смена роли: каждый аккаунт — отдельный пользователь со своей компанией, ролью, клубами,
историей и правами.

## Добавить второй аккаунт

1. Нажмите на блок текущего аккаунта (аватар/имя) вверху меню.
2. В окне «Аккаунты» нажмите **«+ Добавить аккаунт»**.
3. Откроется вход — введите email, пароль и код из письма второго аккаунта.
4. После входа новый аккаунт становится активным. Первый аккаунт остаётся добавленным.

Кнопка «← Отмена» на экране входа вернёт вас к текущему аккаунту.

## Переключиться

1. Откройте «Аккаунты».
2. Нажмите **«Переключиться»** у нужного аккаунта.
3. Приложение перезагрузится и откроет его данные. Активный аккаунт помечен «Активен».

Если у аккаунта написано **«Требуется вход»** — его сессия истекла; нажмите «Войти» и введите код.

## Удалить один аккаунт с устройства

В «Аккаунты» → **«Удалить текущий аккаунт с устройства»**. Остальные аккаунты не затрагиваются.
Если удалить последний — откроется вход.

## Выйти из всех

В «Аккаунты» → **«Выйти из всех аккаунтов»**. Все аккаунты выходят, открывается вход.

## Безопасность

- Пароли на устройстве не хранятся. Хранится только защищённый токен устройства (httpOnly cookie).
- Данные одного аккаунта не видны в другом; переключение всегда сопровождается полной перезагрузкой.
- Выбранная компания/клуб не переносятся между аккаунтами.

На iPhone всё работает и в установленном приложении (с иконки «Домой»).
