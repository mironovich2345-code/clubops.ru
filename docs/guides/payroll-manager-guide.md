# Зарплата для управляющего — инструкция

Управляющий видит зарплату **только своего клуба**. Раздел упрощён до **одного рабочего
экрана**: у управляющего в меню зарплаты только два пункта — **Зарплата** и **Долги**.

## Главный экран — `/payroll`

Открывает сразу рабочий расчёт выбранного месяца (не таблицу периодов и не техничный
обзор). Наверху — компактное переключение:

- **‹ Месяц ›** — предыдущий / выбор месяца / следующий;
- **выбор клуба** — если у вас несколько клубов.

Если период за выбранный месяц уже создан — виден рабочий экран: клуб, месяц, статус,
шапка (Сотрудников / Начислено / К выплате / Требуют решения), прогресс заполнения,
**5 карточек** и список сотрудников, действия периода и согласование.

Если периода **ещё нет** — компактный экран «Расчётный период за … ещё не создан» с
клубом, месяцем, числом активных сотрудников и сотрудников без схемы, и кнопкой
**«Создать период»**. После создания вы сразу попадаете на рабочий экран.

## Где остальные функции

- **Авансы** — 5-я карточка «Аванс» внутри периода (открывает список/оформление аванса);
  детальная карточка аванса и транши — по ссылке из неё. Отдельной вкладки «Авансы» нет.
- **Выплаты** — в карточке расчёта сотрудника, в карточке аванса, в долгах и истории
  периода. Отдельной вкладки «Выплаты» нет.
- **Долги** — отдельный пункт меню (только ваш клуб).
- **Обзор / Сотрудники и схемы / Расчётные периоды / Регионал** — отдельными разделами
  управляющему не показываются. Расчёт зарплаты регионала управляющему недоступен вовсе
  (в т.ч. по прямой ссылке). Проблемы «нет схемы» видны прямо на рабочем экране/карточках.

## Пять карточек

1. **Управляющий** — расчёт самого управляющего (АБ и ПТ отдельно).
2. **Административный состав** — менеджеры продаж, администраторы, ночные менеджеры.
3. **Тренеры ТЗ** — старший тренер ТЗ и тренеры ТЗ.
4. **Тренеры ГП** — старший тренер ГП и тренеры ГП.
5. **Аванс** — вход в раздел «Авансы» (создание/выплата аванса).

Каждая карточка показывает: сотрудников, «заполнено X из Y», проблемы, предварительную
сумму, статус блока. Кнопка «Открыть» показывает сотрудников этой группы; «Открыть расчёт»
у сотрудника — его карточку расчёта. Сверху — прогресс «Расчёт заполнен на N из M».

**Категории ≠ карточки.** В одной карточке (например «Административный состав») —
**разные категории** (менеджер продаж, администратор, ночной), и у каждой **своя
формула**. Уволенные сотрудники в актуальном составе не показываются, но остаются в
истории и в закрытых периодах.

## Что заполняет управляющий

По категории сотрудника в его карточке расчёта заполняются только нужные поля:

- **Управляющий:** АБ план/факт, ПТ план/факт, смены, норма смен. Прибавка/вычет по АБ
  и ПТ считаются отдельно (отклонение от плана ×2, ограничение ±40%).
- **Администратор:** смены (+ норма для контроля). Зарплата = ставка × смены.
- **Менеджер продаж:** смены, выполнение общего плана клуба (%), личная выручка,
  возвраты. Оклад = оклад/15 × смены; процент (по плану клуба) со всей чистой выручки.
- **Ночной менеджер:** ночные смены, выполнение плана клуба (%), личная выручка, возвраты.
- **Тренер ТЗ:** продажи новым, продления, кредит тренера (информационно — на зарплату
  не влияет).
- **Старший тренер ТЗ:** то же + выполнение общего плана ПТ клуба (повышает процент).
- **Тренер ГП:** часы, личные продажи.
- **Старший тренер ГП:** часы, личные продажи, вся выручка ГП клуба (+фикс, +доля).

После ввода нажмите «Рассчитать» — система покажет расшифровку и итог.

## Что управляющий НЕ меняет

- Проценты, окладные части, ставки, пороги, лимиты — это **параметры схемы**, их
  настраивает регионал/ГД/собственник.
- Формулы и схему мотивации.
- Утверждённые корректировки.
- Данные другого клуба.
- Уже утверждённые/закрытые периоды (read-only на сервере).

Изменение схемы **не пересчитывает** уже созданный период — период работает по
зафиксированному снимку параметров (snapshot). Новый месяц использует актуальную схему.

## Дальше по процессу

Заполнили состав → «Отправить на согласование» (панель «Согласование» вверху) →
регионал/бухгалтер утверждают → проводятся выплаты (в карточке расчёта) → закрытие
месяца → остаток превращается в долг. Аванс — 5-я карточка периода (можно до периода).

## Мобильная версия (от 320px)

Один экран, одна колонка: заголовок → переключатель месяца/клуба → KPI → 5 карточек в
столбик → список сотрудников карточками. Меню зарплаты — компактный переключатель из двух
кнопок «Зарплата / Долги» (не 7 мелких вкладок). Без горизонтального скролла; основные
кнопки ≥44px.

## Продажи из ОФД (STAGE 13)

Для менеджеров/ночных/тренеров ГП в карточке расчёта есть блок «Продажи и возвраты»: продажи
из ОФД по подтверждённым кассирам, возвраты, эффективная выручка, ручная корректировка (не
теряется). «Обновить продажи из ОФД» пересчитывает по формуле роли. Сопоставление кассиров —
у регионала/ГД в разделе «Кассиры ОФД». Подробнее — docs/guides/ofd-cashier-mapping-guide.md.
