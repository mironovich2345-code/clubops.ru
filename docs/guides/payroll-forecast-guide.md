# Прогнозный ФОТ — руководство

**Прогноз** — это планируемая стоимость зарплаты на будущий период, рассчитанная из **активных
схем оплаты**. Это число **A** из четырёх (прогноз / бюджет / начислено / выплачено). Оно
**никогда** не сохраняется как факт, **не** попадает в платёжный календарь и **не** меняет бюджет.

## Как считается
`calculatePayrollForecast` (`src/lib/payroll/forecast.ts`) для каждого активного сотрудника:
1. находит действующую схему на дату периода (только утверждённые версии: approved / scheduled /
   active / superseded);
2. берёт **гарантированную (фиксированную) часть** схемы — оклад, который платится даже при нулевых
   продажах (`schemeGuaranteedBase`);
3. агрегирует по клубу / категории / сотруднику / юрлицу.

### Категории прогноза (5)
| Ключ | Ярлык | Позиции |
|---|---|---|
| `management` | Управляющий | manager |
| `administrative` | Административный состав | sales_manager, administrator, night_manager |
| `gym_trainers` | Тренеры ТЗ | тренер/старший тренер ТЗ |
| `group_trainers` | Тренеры ГП | тренер/старший тренер ГП |
| `other` | Другое | всё несопоставленное |

## Честная неполнота (никогда не «тихий ноль»)
Если у части сотрудников:
- **нет схемы** → предупреждение `no_scheme`, `confidence: "partial"`;
- есть **переменная часть** (процент от продаж, план-факт, почасовая) → предупреждение
  `variable_component` (эту часть нельзя спрогнозировать без плановых целей — мы её не выдумываем);
- **не определено юрлицо** → предупреждение `legal_entity_unknown`, сотрудник попадает в «Не
  распределено», а не размазывается по клубам.

Прогноз показывает **гарантированную нижнюю границу** + список предупреждений. Пустой прогноз при
отсутствии данных выводится как «неполный», а не как 0 ₽.

## Где виден
Панель «Зарплата — планирование» на странице **Бюджеты** (вид «Бюджеты»): столбец **Прогноз** с
пометкой «*», если прогноз неполный.

## Что прогноз НЕ делает
- Не переписывает бюджет (см. [salary-budget-guide](salary-budget-guide.md)).
- Не создаёт обязательство к выплате (это делает **утверждённый период**, см.
  [payroll-payment-planning-guide](payroll-payment-planning-guide.md)).
- Не трогает закрытые/утверждённые периоды. Изменение схемы влияет **только** на будущий прогноз.
