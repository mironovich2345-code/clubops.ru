# Управление кассами ОФД

Раздел: **Настройки → Интеграции → ОФД → Кассы ККТ**. Доступ — владелец / ген. директор,
критичные действия под ПИН настроек.

## Список касс
Карточки (мобильно от 320px, без горизонтального скролла): ФН + название, клуб · юрлицо ·
подключение, тип кассы · РНМ · число чеков, статус. Фильтр **Активные / Удалённые / Все**.

## Изменить кассу
«Изменить» → форма со всеми полями: ФН, РНМ ККТ, название, подключение, юрлицо, клуб, тип кассы
и **«Действует с»**. Изменение привязки закрывает предыдущую запись истории и открывает новую с
указанной даты. **Прошлые чеки не меняются** (они снимают клуб/юрлицо/ФН на момент импорта).
Смена ФН: старый ФН остаётся в истории, новый становится текущим; чеки связаны по фактическому
ФН. Активный ФН уникален — при конфликте используйте перенос кассы.

## Удалить кассу
«Удалить»:
- **Пустая касса** (нет чеков) — удаляется полностью.
- **Касса с историей** — архивируется: убирается из активных настроек, синхронизация
  останавливается, текущая привязка закрывается, **все чеки/аналитика/атрибуции сохраняются**.
  Подтверждение честно сообщает: «Касса будет удалена из активных настроек. Исторические чеки и
  аналитика сохранятся».
Архивные кассы видны через фильтр «Удалённые/Все».

## Полное удаление истории (высокий риск)
Отдельное действие для test/dev-данных: доступно **только собственнику**, под ПИН и вводом
номера ФН, с предпросмотром числа удаляемых записей. **Запрещено**, если данные участвовали в
закрытом расчётном периоде. Выполняется в транзакции, с audit-событиями до и после. Обычным
управляющему/регионалу недоступно.
