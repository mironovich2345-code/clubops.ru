# Бюджет зарплаты и его связь с прогнозом — руководство

Бюджет ЗП (число **B**) — это **утверждённый лимит** расходов на зарплату (`Budget` со
`category = "salary"`, помесячно на клуб). Прогноз (**A**) — это ожидаемая стоимость. Они
**разные** и связаны только через **отклонение** и **предложение об изменении** — прогноз
**никогда не переписывает бюджет автоматически**.

## Пять чисел в панели «Зарплата — планирование»
| Число | Значение | Источник |
|---|---|---|
| **Прогноз** | планируемый ФОТ из активных схем | `calculatePayrollForecast` |
| **Бюджет** | утверждённый лимит | `Budget{category:"salary"}` |
| **Начислено** | начислено в утверждённых периодах | `PayrollCalculation.grossAccruedKopeks` |
| **Выплачено** | фактически выплачено | `PayrollCalculation.paidKopeks` |
| **К выплате** | остаток | `PayrollCalculation.remainingKopeks` |

**Отклонение** = Бюджет − Прогноз. Процент = отклонение / прогноз; при прогнозе ≤ 0 —
**«— (прогноз неполный)»**, а не «0 %».

## Режим синхронизации бюджета (`salaryBudgetSyncMode`, по компании)
| Режим | Поведение |
|---|---|
| `manual` | предложения не создаются |
| `suggested` (**по умолчанию**) | дрейф прогноза создаёт **предложение** на согласование |
| `auto_sync` | предложение применяется автоматически — **только при явном включении** |

Порог дрейфа по умолчанию — 5 %. Режим меняет **только** владелец/ГД в форме настроек панели.

## Предложение об изменении бюджета (append-only)
`BudgetChangeProposal` — журнальная запись «было → станет» с причиной и источником
(`forecast_drift | manual | scheme_change`). Статусы: `pending → approved | rejected | superseded`.
Строки **никогда не удаляются**.

- **Кто предлагает:** регионал, владелец, ГД.
- **Кто согласовывает/отклоняет:** только владелец / ГД. (Правило «Реклама — только ГД» не
  затрагивается.)
- Бюджет (`Budget`) меняется **исключительно** через **согласованное** предложение
  (`decideBudgetChangeProposal` делает `upsert` только при `approved`). Создание предложения бюджет
  не трогает.

## Налоги в бюджете
`salaryBudgetIncludesTaxes` (по компании, по умолчанию **выкл.**) — признак того, что лимит
покрывает налоги/взносы. Ставки **нигде не зашиты**.
