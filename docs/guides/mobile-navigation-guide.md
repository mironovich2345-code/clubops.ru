# Мобильная навигация CLUB-OPS

## Меню (drawer)

Нажмите ☰ вверху слева. Меню сгруппировано по смыслу:

- **Главное** — Дашборд, Аналитика, ОФД-продажи.
- **Финансы** — Расходы, Инкассация, Счета, Возвраты.
- **Планирование** — Календарь платежей, Бюджеты.
- **Команда** — Сотрудники, Зарплата.
- **Администрирование** — Пользователи, История, Настройки.

Группы сворачиваются; открытые группы запоминаются. Показываются только доступные вашей роли
разделы. Вверху меню — блок текущего аккаунта (переключение), ниже — выбор компании/клуба.

## Нижняя навигация

Внизу — до 4 основных разделов вашей роли + «Ещё» (открывает полное меню). Набор зависит от роли:

- Управляющий: Главная, Расходы, Счета, Наличные.
- Регионал: Главная, Аналитика, Счета, Расходы.
- Бухгалтер: Стол, Счета, Расходы, Возвраты.
- Собственник/ГД: Главная, Аналитика, Платежи, Продажи.

## Компания и клуб

Контекст компании/клуба меняется отдельно от аккаунта: он переключает доступную компанию/клуб
**внутри текущего аккаунта**, тогда как переключатель аккаунтов меняет самого пользователя.

См. также: [add-switch-account-guide.md](add-switch-account-guide.md).
