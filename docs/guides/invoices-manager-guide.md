# Счета — инструкция управляющему

## Как создать счёт
1. Загрузите файл счёта — система распознаёт поля (ИИ).
2. Проверьте/заполните доступные поля (контрагент, сумма, ИНН и т. д.).
3. Нажмите **«Создать счёт»**.

Отдельной отправки на проверку нет: счёт **сразу уходит региональному директору**. После
успеха — «Счёт создан и отправлен региональному директору».

## Что дальше
- Регионал согласует → счёт поступает бухгалтеру.
- Бухгалтер может доредактировать распознанные ИИ-поля на карточке счёта.
- Оплата блокируется при низкой уверенности распознавания (и при средней — если пустые
  критичные поля), пока данные не проверены. Это не мешает созданию и согласованию.

## Важно
- Нужен загруженный документ; повторная отправка формы не создаёт дубль (clientSubmissionId).

## Мобильная версия (WAVE 2)

С телефона раздел работает от 320px без горизонтального скролла. Списки показываются
компактными карточками (полная таблица — на компьютере). Документы открываются встроенным
просмотрщиком (фото — с масштабированием, PDF — по нажатию), без перехода в новую вкладку.
Главное действие («Создать»/«Далее») закреплено внизу и не прячется под клавиатурой. Поля не
увеличиваются при фокусе. Установка на «Домой» и вход — см. руководство по установке.
