# Возвраты — инструкция управляющему

## Как оформить возврат
1. Выберите тип (абонемент / персональные тренировки).
2. Загрузите **4 обязательных документа**, заполните данные клиента и банковские реквизиты.
3. Выполните расчёт (АБ или ПТ) — система посчитает сумму к возврату.
4. На финальном шаге нажмите **«Создать возврат»**.

Отдельной кнопки «Отправить» и повторного подтверждения нет: после создания возврат **сразу
уходит региональному директору**. После успеха — «Возврат создан и отправлен региональному
директору».

## Что дальше
- Регионал согласует → возврат передаётся бухгалтеру → оплата по текущей логике.
- Регионал может **вернуть на исправление** с комментарием. Тогда исправьте и нажмите
  **«Исправить и отправить повторно»**.

## Важно
- Пока не загружены все документы и не заполнен расчёт/реквизиты — кнопка недоступна.
- Расчёты АБ/ПТ, сроки и суммы не изменились.

## Мобильная версия (WAVE 2)

С телефона раздел работает от 320px без горизонтального скролла. Списки показываются
компактными карточками (полная таблица — на компьютере). Документы открываются встроенным
просмотрщиком (фото — с масштабированием, PDF — по нажатию), без перехода в новую вкладку.
Главное действие («Создать»/«Далее») закреплено внизу и не прячется под клавиатурой. Поля не
увеличиваются при фокусе. Установка на «Домой» и вход — см. руководство по установке.
