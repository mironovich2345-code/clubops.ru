# Руководство регионального директора: предложение изменений зарплаты

Вы можете **предложить** изменение закрытых для управляющего параметров зарплаты. Предложение
**не влияет на расчёт**, пока его не согласует ГД или собственник.

## Как предложить изменение
1. Откройте расчёт сотрудника: **ФОТ → Расчётные периоды → период → сотрудник**.
2. Внизу карточки — блок **«Изменения и согласования»** → **«Предложить изменение»**.
3. Выберите, что изменить:
   - **Разовая премия** — доплата за этот период (после согласования станет отдельной строкой
     начисления, движения денег не создаёт).
   - **Окладная часть / Процент / Порог / Норматив** — параметр схемы. Можно предложить:
     - **Разово в этом периоде** — коснётся только этого расчёта, живую схему не меняет.
     - **С будущей даты** — новая схема с указанной даты (прошлые расчёты не трогаются).
4. Укажите новое значение. Под полем видно **текущее** значение.
5. Обязательно напишите **причину/обоснование** для ГД.
6. Отправьте. Система покажет **влияние на начисление** (насколько изменится сумма). Если базы
   для расчёта нет (например, не введена выручка) — покажет «Невозможно рассчитать влияние», а
   не ноль.

## Что можно и чего нельзя менять
Разрешены только «денежные» параметры схемы сотрудника (оклад, процент, порог, норматив, уровни
процента) и разовая премия. **Нельзя** менять компанию/клуб/сотрудника, категорию, формулу,
согласованный snapshot, уже выплаченные суммы, авансы — это заблокировано на сервере.

## После отправки
- **На согласовании** — ждёте решения ГД. Итог сотрудника пока не меняется.
- **Возвращено на доработку** — ГД просит уточнить. Отредактируйте комментарий и отправьте
  повторно (ревизия увеличится, история сохранится).
- **Согласовано / Применено** — изменение вошло в расчёт.
- **Отклонено** — расчёт не изменился.
Свою заявку можно **отменить**, пока она не решена. Согласовать собственную заявку нельзя.

## Важно
- Пока по сотруднику есть незакрытая заявка, **период нельзя закрыть** — сначала дождитесь
  решения ГД или отмените заявку.
- Всё работает с телефона (от 320px).
