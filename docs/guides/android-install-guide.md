# Установка CLUB-OPS на Android

На Android CLUB-OPS устанавливается как PWA-приложение через Chrome (или другой браузер на
движке Chromium). В отличие от iPhone, здесь есть настоящая кнопка установки.

## Способ 1 — кнопка в приложении (проще всего)

1. Откройте CLUB-OPS в **Chrome**.
2. Перейдите на страницу **`/install`**.
3. Если браузер предлагает установку, появится кнопка **«Установить приложение»** — нажмите её.
4. Подтвердите установку в системном окне Chrome.

Кнопка появляется только когда Chrome считает сайт устанавливаемым (есть манифест, иконки,
HTTPS). Если её нет — используйте способ 2.

## Способ 2 — меню Chrome

1. Откройте CLUB-OPS в Chrome.
2. Нажмите меню **⋮** (три точки, вверху справа).
3. Выберите **«Установить приложение»** или **«Добавить на главный экран»**.
4. Подтвердите.

Иконка CLUB-OPS появится в списке приложений и/или на главном экране.

## Что вы получите

- Запуск в отдельном окне (standalone), без адресной строки.
- Учёт системных отступов (safe-area) — контент не под системными панелями.
- Сохранение входа в защищённой cookie.
- Свежие финансовые данные из сети (кешируются только статические ресурсы).

## Частые вопросы

**Нет кнопки «Установить приложение».**
Убедитесь, что вы в Chrome и на HTTPS-адресе. Иногда Chrome предлагает установку не сразу —
воспользуйтесь способом 2 через меню ⋮.

**Firefox / другой браузер.**
Поддержка установки лучше всего в Chrome. В других браузерах ищите пункт «Добавить на главный
экран» в меню; поведение может отличаться.

**Как обновить.**
Обновление приходит автоматически. При баннере «Доступно обновление» нажмите его.
