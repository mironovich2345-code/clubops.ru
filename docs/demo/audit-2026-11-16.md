## Состояние основных направлений

| Направление | Итог |
| --- | --- |
| Дашборд и план/факт | Демоданные, аналитическая сводка, распределение по филиалам; роль/филиал влияют на доступ и видимые суммы |
| Аналитика и ОФД | Страницы открываются; офлайн-чеки синтетические; номенклатура недоступна, если позиции товаров/услуг не загружены |
| Сверка ОФД ↔ эквайринг ↔ CRM | **Расчётный синтетический эталон**, реальные подключения к банку и CRM отсутствуют; это явно обозначено в UI |
| Расходы, счета, инкассация, календарь, бюджеты | Реальные server actions в изолированной демобазе; предыдущие тесты финансовых циклов пройдены |
| Сотрудники и зарплаты | Ролевой доступ, начисления, авансы/выплаты, запрет переплат — по предыдущему функциональному QA; nested-подразделы открываются по HTTPS |
| Возвраты | Ролевой маршрут и карточки открываются; полный цикл ранее проверялся на локальной тестовой PostgreSQL |
| Документы | Навигационный хаб к существующим вложениям; отдельный каталог со сквозным поиском/фильтрами отсутствует |
| Настройки/интеграции | Просмотр части настроек; реальные внешние действия, OTP/почта, ОФД, Telegram, платежи отключены в деморежиме |

## Проверенные защитные границы

- Runtime демо требует `DEMO_MODE=true`, строгий `APP_URL` и имя базы `clubops_demo_*`.
- Railway demo использует свою PostgreSQL и volume, без public TCP proxy базы.
- Данные посетителей создаются в независимых tenant; ролевые права применяются сервером. Защита от подмены ID, TTL, reset и лимиты ранее проверялись в DB/browser тестах.
- `noindex`/CSP/запрет внешних интеграций на уровне middleware; исходные креденшелы production не переносились.
- Сервисное задание cleanup выполняется, но необходимо продолжать мониторинг ошибочных запусков и хранения просроченных сессий.
- URL preview технически доступен всем, кто его знает: **noindex не является паролем**. До размещения в портфолио требуются финальная проверка UX и решение о публичном доступе.
