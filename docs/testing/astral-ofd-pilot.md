# Астрал.ОФД — живой пилот (чек-лист)

Выполняется **только при наличии действующего `api_key`**. Пока ключа нет — статус
**READY FOR CREDENTIALS**: код и фикстуры проверены (`npm run pilot:ofd-astral`), но LIVE
не заявляется и не симулируется. Не запускать массовую историю до успешной сверки одного дня.

## Что должен заполнить пользователь в UI

1. `Настройки → Интеграции → Подключение ОФД → ОФД Астрал` (owner / ген. директор).
2. **Шаг 1.** Вставить `api_key` Астрал.ОФД → «Сохранить ключ» (нужен ПИН настроек) →
   «Проверить подключение» (должно вернуть число организаций).
3. **Шаг 2.** «Загрузить организации» → выбрать организацию → выбрать юрлицо CLUB-OPS →
   «Сохранить привязку» (ПИН).
4. **Шаг 3.** «Загрузить торговые точки» (справочно).
5. **Шаг 4.** «Загрузить кассы» → для каждой кассы выбрать Клуб + Юрлицо → «Привязать» (ПИН).
6. **Шаг 5.** Выбрать кассу и диапазон **1 день** → «Предпросмотр».

## Сверка одного тестового дня (перед импортом)

Сравнить блок предпросмотра с кабинетом Астрал за тот же день и кассу:

- [ ] количество документов;
- [ ] продажи (приход) и возвраты;
- [ ] наличные / электронные;
- [ ] итоговая сумма (приход − возвраты);
- [ ] позиции (если приходят);
- [ ] сверка с «закрытыми сменами» (сумма/чеки) — расхождение ≈ 0;
- [ ] сверка с «аналитикой» (profit/refunds) — расхождение ≈ 0;
- [ ] служебные/неизвестные документы НЕ учтены в выручке.

Если расхождения значимые — **не импортировать**; уточнить маппинг `documentType`/`operationType`
и единицы сумм (`astral-ofd-implementation.md` §6–7), затем повторить предпросмотр.

## Импорт и проверки

7. «Импортировать» (идемпотентно).
8. Проверить `OfdReceiptImport` (чеки), `OfdReceiptItem` (позиции, если были).
9. Проверить `OfdDailySalesSummary` / `OfdRevenueCategoryDailySummary`.
10. Проверить дашборд (чип «Астрал — В норме») и аналитику ОФД.
11. Проверить «Фактические деньги» (наличная выручка Астрал видна).
12. **Повторить импорт того же дня** → `duplicatesSkipped`, новых чеков 0, сумм не задвоило.
13. Только после успешной сверки — расширять диапазон.

## Инфраструктура

- `OFD_INTEGRATIONS_ENABLED=true`, `OFD_SECRET` (≥32), `CRON_SECRET`; внешний таймер на
  `POST /api/cron/ofd/daily` (ночной sync берёт и Такском, и Астрал независимо).
