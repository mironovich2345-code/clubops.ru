## Что запустить локально для скриншот-приёмки (§8)

Playwright-harness готов, но в dev-песочнице **не запускался** (нет сети → нет установки браузера;
вход по email-OTP). Запуск у вас:

```
npm i -D @playwright/test && npx playwright install chromium
npm run dev
# сохранить авторизованную сессию (см. tests/visual/README.md) → tests/visual/.auth/state.json
BASE_URL=http://localhost:3000 PW_STORAGE=tests/visual/.auth/state.json npm run test:visual
npm run test:visual:contact   # → artifacts/mobile-visual-polish-part2/index.html
```
