# Ручной чек-лист проверки на iPhone (PWA)

Эти проверки **нельзя автоматизировать** без реального устройства — они закрывают §29 ТЗ.
Выполняются на живом iPhone (желательно двух размеров: SE/mini и Pro Max) в Safari.
Отмечайте ✅ / ❌ и фиксируйте версию iOS.

Устройство: __________  iOS: ______  Дата: ______  Проверял: ______

## A. Установка и запуск

1. [ ] Открыть CLUB-OPS в Safari — страница грузится, без горизонтального скролла.
2. [ ] «Поделиться» → «На экран „Домой"» доступно, иконка добавляется.
3. [ ] Иконка на экране «Домой» — правильная (монограмма CO), не белый квадрат.
4. [ ] Запуск с иконки открывает приложение **на весь экран** (нет адресной строки Safari).
5. [ ] `@media (display-mode: standalone)` активен: подсказки «установить» не показываются.

## B. Safe-area и раскладка

6. [ ] Верхний sticky-бар не заходит под «чёлку»/Dynamic Island (учтён `safe-area-inset-top`).
7. [ ] Нижняя навигация не перекрыта системным индикатором (учтён `safe-area-inset-bottom`).
8. [ ] Ландшафтная ориентация: контент не уходит под скруглённые углы/боковые вырезы.
9. [ ] Нет наложения header/footer/кнопок на контент ни на одном ключевом экране.

## C. Ввод и зум

10. [ ] Тап в поле ввода (сумма, поиск) **не вызывает авто-зум** Safari.
11. [ ] Пользовательский зум щипком **работает** (accessibility не отключён).
12. [ ] Экранная клавиатура не перекрывает активное поле/кнопку сохранения.

## D. Ширина 320px и ключевые страницы

13. [ ] На узком экране (SE/mini, 320–375px) нет горизонтального скролла страницы.
14. [ ] Расходы / Счета / Возвраты: списки читаемы, действия доступны, длинные ФН/UUID
       переносятся (`break-anywhere`), не ломают ширину.
15. [ ] ФОТ (payroll): таблицы/карточки прокручиваются внутри своих контейнеров, не тянут
       страницу вширь.

## E. Навигация

16. [ ] Гамбургер открывает drawer с **полной** навигацией по роли (нет запрещённых пунктов).
17. [ ] Нижняя навигация: до 5 пунктов, «Ещё» открывает drawer, активный пункт подсвечен.
18. [ ] Переход по ссылке закрывает drawer; фон под drawer не скроллится.

## F. Сессия, сеть, обновление

19. [ ] Закрыть и снова открыть с иконки — вход **сохранён** (не просит логин заново).
20. [ ] Включить авиарежим и открыть страницу — показывается честная «Нет подключения»
       (а не устаревшие суммы); «Повторить» после возврата сети работает.
21. [ ] После деплоя новой версии появляется баннер «Доступно обновление»; тап обновляет без
       потери введённых данных вне формы.
